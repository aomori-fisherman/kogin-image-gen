# こぎん図案ジェネレータ — 画像/ロゴ → こぎん風チャート（MVP）

> 作成: 2026-07-14
> スコープ: 機能(b)「画像→こぎん図案生成」の**とりあえず動くMVP**

## これは何か

客がアップロードした写真・画像・ロゴを基に、**こぎん（刺し子の一種）風の図案チャート**を
決定論アルゴリズムで生成する、完全クライアントサイドの単一ページアプリ。

- **伎海の課金導線プロダクトのMVP**。ハートスポット向けの無償こぎんアプリ
  （`C:\dev\heartspot-kogin-app`・CC BY 想定）とは**別プロダクト**。
  コードは混ぜていない（無償版に import 依存しない・美観だけ独立再現）。
- **AI・バックエンド・外部APIキーは一切使わない。** 画像の輝度をこぎんの刺し目に
  写像する純粋な画像処理。→ そのまま静的ホスティング（Vercel等）にデプロイ可能。

## できること（MVP）

1. **画像アップロード** — ファイル選択 / ドラッグ&ドロップ / 組み込みサンプル。
2. **グリッド化** — 横の目数を指定（奇数に丸め・こぎん基調）。縦は画像の縦横比から自動算出。
   画像を各セルの平均輝度にダウンサンプル。
3. **量子化** — 輝度を 2〜4 段階にしきい値量子化。コントラスト・しきい値バイアス・反転つき。
   透明背景（ロゴのPNG）は「明＝非刺し」として扱う。
4. **こぎん風レンダリング（producible＝実際に刺せる）** — 藍地×白糸で刺し目を描画。
   面（べた）を「長い横バー1本」で塗らず、**短い渡り（最大7目）＋隙間**に分解し、
   隙間位置を行ごとにオフセットして **ひし形/モドコ調の段々こぎん充填** にする。
   - `横流れ刺し`（既定）: こぎんらしい水平の走り刺し。
   - `升目の塗り`: 濃淡は糸の太さで表現（面は同じく短い渡りに分解）。
5. **書き出し** — 生成チャートをそのまま **PNG でダウンロード**。

## ⚠ producible ルール — 渡り長の上限 = 7目

こぎんは **一本の渡り糸(float)** が長すぎると引っかかる/糸が抜ける/締まりすぎて **実際に刺せない**（所長確認・2026-07-14）。オーダーメイド/ふるさと納税で実物を刺す商品なので producible が必須。

- `kogin-render.js` の `FLOAT_MAX = 7`。`splitRun()` が長い面を **最大7目の渡り＋1目の隙間** に自動分解（隙間を行ごとにオフセットして段々に）。
- `buildStitchMap()` が「実際に糸が乗るセル」の真実マップを作り、`render()` の返り値 `violations`（`verifyFloats()`）で **float>7 が1つも無いこと** を機械検証できる。

## 動作確認（このMVPで検証済み）

- **純関数層**: `node test/algo-test.cjs` → 12 passed（グリッド奇数丸め・ダウンサンプル・量子化・反転・バイアス）。
- **producible検証**: `node test/producible-test.cjs` → 3320 passed（splitRunで全長を最大7目に分解・段々オフセット・16×12/50×30ベタ塗りでfloat>7ゼロ）。
- **実パイプライン検証**: `node test/pipeline-producible.cjs` → ベタ四角/菱形/太バー（生float 45〜55）が全て split後 float≤7・violations 0。
- **フルパイプライン（ヘッドレスChrome）**: `test/harness.html` を
  `chrome --headless=new --dump-dom` で実行 → `ok:true`（画像読込→グリッド→量子化→
  こぎん描画→`toDataURL`書き出しまで全チェック green）。サンプル画像で 41×41 目・
  刺し目362セル・606×401px の PNG を書き出せることを確認済み。
- 生成チャートの見た目（藍地×白糸の横流れ刺しで菱形図案が読める）も目視確認済み。

## ファイル構成

```
kogin-image-gen/
  index.html            単一ページ
  css/style.css         ダーク基調UI（heartspot版と独立・import依存なし）
  js/
    image-loader.js     file input / D&D / URL → canvas 読み込み
    quantize.js         グリッド寸法・輝度ダウンサンプル・N段階量子化（純関数）
    kogin-render.js     level行列 → こぎん風チャート描画（藍地×白糸）
    sample.js           組み込みサンプル画像（外部ファイル不要）
    app.js              UI結線・パイプライン統括
  test/
    algo-test.cjs       純関数層テスト（Node）
    harness.html        フルパイプラインのヘッドレス検証用
  README.md
```

外部ライブラリ・CDN・ビルドツールは**一切なし**（vanilla JS のみ）。

## v2 アイデア（今回やらない・引き継ぎメモ）

- **196モドコの"部品化"タイル配置**: 既存の伝統モドコ（升目単位の刺し目文様）を
  画像の輝度/領域にマッチさせてタイル配置し、authentic なこぎん図案を組む本格版。
  MVPは輝度→格子刺し目の写像に留めている（"それっぽさ"優先）。
- **こぎん文法の厳密化（残り）**: フロート長≤7は担保済み（producibleルール参照）。
  残るは奇数目・裏渡りの厳密制約。196モドコのタイル配置(下記)と併せてv2で。
- **(a) 言葉だけで図案生成**: テキスト意図→図案ドラフト。**別タスク**（今回のスコープ外）。
- チャート出力の高度化: 目数目盛り・色番号・印刷用PDF・刺し順ガイド等。
- パレット選択（藍以外の地色・複数糸色）。
